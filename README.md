# Chinmayee's 13th Birthday Surprise 🎉

A single-page birthday surprise site: solve a puzzle, pop balloons, get a birthday wish.

## How to view it

This site is hosted with GitHub Pages — open the Pages URL once it's live (see repo settings / About section).

## Files

- `index.html` — the whole site (puzzle, balloon pop game, wish screen)
- `birthday-video.mp4` — background video that plays behind the puzzle
- `birthday-song.mp3` — the birthday song, plays once all 4 balloons are popped
